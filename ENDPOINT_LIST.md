| Method | Path | Purpose | Maps to Need |
|---|---|---|---|
| `GET` | `/found-items/{itemId}` | Return the found-item record (`status`, `location`, `dateFound`, `description`, `category`) for a given ID. | Team 11 needs to look up a found item by item ID from Team 10, in order to check whether a product that just went missing has already been logged as found. |
| `GET` | `/found-items/{itemId}` | Return a `null` or `404 Not Found` response when no found item exists with the queried ID. | Team 11 needs to receive a null/no-match response from Team 10 when no found item matches the queried ID, in order to avoid raising false follow-up alerts. |
| `GET` | `/found-items` | Return the full found-items list as read-only data for inventory-side browsing against Team 10's Lost & Found table. | Team 11 needs read-only access to the found-items table from Team 10, with no create, update, or delete permissions, in order to ensure inventory-side queries can never modify Lost & Found records. |
| `GET` | `/found-items?category={category}&keyword={keyword}` | Search found items by category and keyword when an exact ID match is uncertain, in order to surface candidate matches. | Team 11 needs to search found items by category and keyword when an exact ID match is uncertain, in order to surface candidate matches for review. |
| `GET` | `/found-items?updatedSince={timestamp}` | Return found items whose status changed after a given timestamp, supporting incremental synchronization. | Team 11 needs to detect found items whose status has changed recently, in order to avoid re-checking the entire table on every sync. |
| `POST` | `/found-items/batch-lookup` | Check a batch of missing-inventory IDs against found items in a single request, supporting daily reconciliation. | Team 11 needs to check a batch of recently missing inventory items against Team 10's found items in one call, in order to run daily reconciliation without making `N` sequential requests. |
| `POST` | `/flagged-checks` | Record that a specific found item was checked against a missing inventory item for audit-trail purposes. | Team 11 needs to record that a given found item was checked against a missing inventory item, in order to maintain an audit trail of reconciliation attempts. |
